📥 Import YouTube Subscriptions (Zero Setup)

Export all your favorite streamers from Google in 1 minute with 0 API key:

1
Go to takeout.google.com and click "Deselect all".
2
Scroll down and check only YouTube and YouTube Music.
3
Click "All YouTube data included", deselect all, and check only subscriptions.
4
Click "Next step" ➔ "Create export", download the .zip, and drag subscriptions.csv into the 👥 Channels tab!

🔑 YouTube API Key (Optional)

✨ Optional! Controller Notify works 100% free without any API key.

If you wish to configure your own Google Cloud API quota:

1
Go to console.cloud.google.com and create a new project.
2
In the search bar, look for "YouTube Data API v3" and click Enable.
3
Go to APIs & Services ➔ Credentials and click "Create Credentials" ➔ "API key".
4
Copy your API key and paste it into the ⚙️ General tab.
